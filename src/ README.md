# Proyecto de Algebra Lineal

## Integrantes

1. Jarel - Lider e integracion del proyecto.
2. Yasir - Operaciones basicas con vectores.
3. Wilbert - Operaciones avanzadas con vectores.
4. Jeydel - Operaciones con matrices.
5. Maycol - Transformaciones elementales.
6. Cristobal - Pruebas y documentacion.

## Temas del proyecto

- Operaciones con vectores.
- Operaciones con matrices.
- Transformaciones elementales de matrices.

## Lenguaje de programacion

Java.

## Objetivo

Desarrollar un programa que permita al usuario seleccionar
un tema de Algebra Lineal, ingresar sus propios datos
y obtener los resultados de las operaciones.

## Archivos Java

- Main.java
- VectoresBasicos.java
- VectoresAvanzados.java
- OperacionesMatrices.java
- Transformaciones.java

## Ejecucion

Compilar todos los archivos:

javac *.java

Ejecutar el programa:

java Main
